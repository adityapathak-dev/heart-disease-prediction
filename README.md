# Heart Disease Prediction

A machine learning project that predicts heart disease presence using a trained Random Forest classifier and a FastAPI web application.

## Features

* Random Forest classification model
* Data preprocessing using scikit-learn
* FastAPI backend for predictions
* Web interface built with HTML, CSS, and JavaScript
* Interactive patient input form
* Model prediction displayed in plain English

## Tech Stack

* Python
* Pandas
* Scikit-learn
* FastAPI
* Uvicorn
* HTML, CSS, JavaScript

## Run Locally

1. Clone this repository.

2. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Start the application:

   ```bash
   uvicorn main:app --reload
   ```

4. Open http://127.0.0.1:8000 in your browser.

API documentation is available at http://127.0.0.1:8000/docs.
